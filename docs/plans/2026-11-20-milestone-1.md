# Milestone 1 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Prove world-id detection from live logs, VRChat login+2FA, and a successful orange/red status update that sticks in-game.

**Architecture:** `VrchatPrivacy.Core` owns pure parse/rules/decision + session interfaces; `VrchatPrivacy.App` is a thin WinForms tray. Milestone 1 can use a console harness if tray login UX is incomplete.

**Tech Stack:** .NET 8, WinForms, VRChat.API 2.24.0, xUnit, Windows DPAPI for cookies.
